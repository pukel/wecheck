WeCheck — готовый сайт

В архиве актуальная версия: все 6 страниц инструкции идут подряд при прокрутке.

ДЛЯ ПРОСМОТРА
Распакуйте архив и откройте index.html в браузере.

ДЛЯ ХОСТИНГА
Загрузите содержимое архива в корневую папку сайта.
index.html, styles.css, app.js и папка assets должны оставаться рядом.
Сборка, Node.js, сервер приложений и база данных не нужны.
Для корректной работы копирования почты используйте HTTPS.

GITHUB PAGES
1. Создайте публичный репозиторий.
2. Загрузите распакованные файлы и всю папку assets, сохраняя вложенные папки.
   Сам ZIP-файл в репозиторий загружать не нужно.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
